# Third-party materials

## Dependencies

Python and JavaScript dependencies are declared in requirements*.txt and frontend/package*.json. They are retrieved during installation, not vendored in this source export. Their own licenses, copyright notices and distribution obligations continue to apply. Consult upstream packages and installed license files.

## Fonts

The browser UI uses a system-font stack. No original bundled font binaries are included. The example container installs distribution-packaged Noto CJK fonts; retain the distribution package copyright/license files when redistributing a built image. Optional locally installed font paths in the code do not include those font files.

## Maps and data

Map-layer integrations can request third-party services, including Esri imagery. Their provider terms and required attributions apply. Four English-annotated original screenshots and a three-frame GIF are included for portfolio review, but detailed basemap/grid panes and assessment values are covered. All three GIF frames are English-annotated and data-protected; playback timing is not execution latency. No synthetic assessment values or replacement numerical results are supplied. Raw imagery files, assessment databases and full report exports are not distributed. Supply only compatible data you are authorized to use.
